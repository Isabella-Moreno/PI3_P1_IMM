## Funcionalidades
- **Ejercicio 1 (`Ejercicio1`):** Implementación de la clase abstracta `Figura` con el método abstracto `calcularArea()` y el método concreto `mostrarArea()`, extendida por `Circulo` y `Rectangulo` (`FiguraPrueba`).
- **Ejercicio 2 (`Ejercicio2`):** Implementación de la clase abstracta `Empleado` con `calcularSalario()` y `mostrarDetalles()`, extendida por `Gerente` (salario base + bono) y `Vendedor` (salario base + comisión) en `EmpleadoPrueba`.
- **Ejercicio 3 (`Ejercicio3`):** Demostración del error de compilación al intentar instanciar directamente una clase abstracta (`Instrumento`) y análisis del impacto de definir como concreto un método que debería ser abstracto (`Guitarra` y `UsoIncorrectoAbstractaPrueba`).
